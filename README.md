# KCL Cosmology Hackathon 2026 – Solution Repository

This repository contains my solution code for the KCL Cosmology Hackathon 2026, held on 5 June 2026. (Thanks to Professor Malcolm Fairbairn and his helpers for organizing this!) The challenge consisted of three data analysis and machine learning exercises focused on statistics, cosmology, and galaxy redshift estimation.

The required Python libraries for this to run are pandas, matplotlib, numpy, itertools, and scikit-learn.
